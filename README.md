# 规培手写门诊病历自动排版

面向规培/跟师场景：把非结构化或半结构化的门诊病历文本，经 AI 改写与校验后，自动切割多患者记录，并填入手写体排版模板，输出可直接使用的 JSON。

支持批量处理、OpenAI 兼容接口改写、多患者自动切割、结构化校验与失败样本回放。

## 🚀 快速开始

### 1. 环境要求
- Windows 操作系统 (推荐)
- Python 3.8 或更高版本

### 2. 安装与启动
本项目包含一个自动化启动脚本，可以自动检测并安装所需的依赖库。

1.  **下载项目**: 将项目文件下载到本地目录。
2.  **运行启动脚本**:
    - 双击运行 `start.py` (如果已关联 Python)。
    - 或者在终端/命令行中运行:
      ```bash
      python start.py
      ```
3.  **自动配置**:
    - 脚本会自动检查 `streamlit`, `requests`, `psutil` 等依赖。
    - 如果缺失依赖，脚本会提示并尝试自动安装。
    - 脚本会自动检测端口 8501 是否被占用，并提供重启或停止选项。
4.  **访问应用**:
    - 启动成功后，浏览器会自动打开 `http://localhost:8501`。

## 📖 使用指南

### 核心功能

1.  **批量病历切割**:
    - 上传包含多个患者记录的 `txt` 文件。
    - 系统会自动识别 "姓名：" 字段进行切割。
    - 支持自定义分割标记（例如 "---"）。
    - 切割后的文件会自动命名为 `序号-姓名-年龄-诊断.txt`。

2.  **AI 改写并提取**:
    - 适用于格式混乱、手写识别导出或非标准格式的病历。
    - **配置 API**: 点击右上角的 "⚙️ API 设置"，输入你的 OpenAI 兼容接口地址 (如 ChatGPT, DeepSeek, LocalLLM 等) 和 Key。
    - **上传与处理**: 上传原始文本，系统会调用 AI 将其改写为标准格式，然后自动提取为 JSON。

3.  **基础 JSON 提取**:
    - 适用于已经是标准格式（包含“四诊”、“处方”等明确标题）的文本文件。
    - 直接上传即可转换为结构化 JSON。

### 注意事项
- **文件编码**: 请确保上传的 `txt` 文件使用 **UTF-8** 编码，否则可能会出现乱码。
- **API 费用**: 使用 AI 改写功能会消耗 Token，请确保你的 API Key 有足够的额度。
- **隐私安全**: 如果使用第三方 AI API，请注意患者隐私数据的脱敏。本地部署的模型则无此担忧。

## 📂 文件结构说明

以下是项目中主要文件的功能介绍，帮助你快速理解系统架构：

| 文件名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `start.py` | **启动脚本** | 项目入口。负责环境检查、依赖安装、端口管理和启动 Streamlit 服务。建议总是通过此脚本启动。 |
| `visual_interface.py` | **主程序** | 基于 Streamlit 的图形界面。侧边栏配置模板/API/提示词，主区按工作流分 Tab 处理。 |
| `record_parser.py` | **核心解析** | 统一章节抽取、姓名/年龄/诊断解析、多患者切割、结构化校验、模板填充。 |
| `api_client.py` | **API 客户端** | OpenAI 兼容接口调用，429/超时自动退避重试。 |
| `split_records.py` | **切割 CLI** | 委托 record_parser，命令行切割多患者文件。 |
| `extract_medical_record.py` | **抽取 CLI** | 命令行五段抽取，便于脚本化批处理。 |
| `api_config.json` | **配置文件** | 存储 API 设置（不入库）。参考 `api_config.example.json`。 |
| `prompt_config.json` | **提示词** | AI 改写提示词，支持版本历史与回滚。 |
| `template/` | **模板目录** | 排版 JSON 模板及 `*.map.json` 章节映射。 |
| `output/` | **数据目录** | AI 改写结果与 JSON 输出。 |
| `split_output/` | **数据目录** | 病历切割结果。 |
| `test_*.py` | **测试** | 功能自测与稳定性测试。 |

## 🛠️ 常见问题

**Q: 启动时提示 `ModuleNotFoundError`?**
A: 请直接运行 `python start.py`，它会自动修复缺失的依赖。

**Q: 端口 8501 被占用怎么办?**
A: `start.py` 会检测到并询问你是否要结束占用该端口的进程，选择 "1" (重启) 即可。

**Q: AI 改写失败?**
A: 请检查 API 设置中的 URL 和 Key 是否正确，以及网络是否通畅。可以在设置面板点击 "🔌 测试连接" 进行验证。
